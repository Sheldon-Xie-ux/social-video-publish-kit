# 开工卡（每次开新任务，整段贴给 agent）

> 用途：剪辑、字幕、封面、上传、修改、删除。默认 dry-run，未验收不得发布。

做视频/封面/发布任务时，先不要上传、删除、覆盖任何线上内容。

1. 先读：`specs/字幕规范.md`、`specs/封面规范.md`、`specs/发布坑位清单.md`、`templates/manifest.json`（没有就按模板新建）。
2. 文档与代码/成品冲突时，先列冲突并停止，不许自己挑一个旧的用。
3. 先回答这 7 项再动手：
   - 目标平台
   - 目标作品（ID + 标题，改/删必填）
   - 版本号
   - 输入文件路径 + sha256
   - 画布尺寸 / 封面比例
   - 字幕规范（字号、断行、距底）
   - 验收证据清单（首帧、裁切图、亮背景帧、列表截图）
4. 默认只 dry-run；发布/删除/覆盖必须单独确认。
5. 每次点击后做**对象级断言**：不是"clicked"，而是目标状态已改变。
6. 上传必须等真实完成信号；禁止固定 sleep 后直接发布。
7. 发布后回列表核对标题/时长/封面/可见范围，截图。
8. 任一步失败：立刻停同类操作，写失败记录，给一个修复方案，不许连续盲试。
9. 交付时给：首帧、3:4 与 16:9 裁切模拟图、亮背景字幕帧、音画同步检查点。
10. 报告区分：已验证事实 / 推断 / 未知。

## 验收通过才允许发布

- [ ] 首帧 = 设计封面
- [ ] 3:4 与 16:9 裁切都不切字、不切脸
- [ ] 字幕字号、断行、时间轴、亮背景可读性通过
- [ ] 开头/中段/结尾音画同步
- [ ] 上传真实完成，字段与 manifest 一致
- [ ] 回列表截图，标题/时长/封面/可见范围正确
- [ ] 无重复、无误删、无未说明变更
