# 视频封面规范

> v1 · 2026-11-02 · 依据用户两次否稿后的明确要求
> **此文件为封面制作的唯一标准，后续一律照此执行。**

---

## 一、色调铁律：只能暖色，不能冷色

**用户原话：「色调一定要暖色调，绝对不能够再做冷色调。」**

### 禁止

| 禁止项 | 说明 |
|---|---|
| 深蓝 / 青蓝 / 冷紫 | 科技蓝、赛博紫、深空蓝一律不允许 |
| 黑底、暗调、夜景霓虹 | 「阴暗风」被明确否掉 |
| 冷色阴影 | 阴影不用蓝紫，用暖褐 |
| 高反差冷光 | 不要轮廓冷光 |

### 必须

| 必须项 | 参考色值 |
|---|---|
| 背景暖光 | `#FFF3E0` `#FFE0B2` `#FFD8A8` |
| 阳光感 / 室内暖灯 / 木色 / 米白 | `#F5E6D3` `#E8CBA8` |
| 强调黄 | `#FFC107` `#FFD54F` |
| 强调橙 | `#FF8A3D` `#FF6B35` |
| 文字底色 | 米白 / 奶油白，不用纯冷白 |

**判断方法**：把封面缩小到手机大小看一眼，如果是「明亮、温暖、像白天拍的」，通过；如果「暗、冷、像夜里机房」，返工。

---

## 二、人物要求

1. **必须是正面正脸**，眼睛看向镜头
2. 表情：自信 / 认真 / 微微带笑，不要面无表情
3. 衣服：暖色或浅色（米白、浅驼、暖橙），**不要纯黑**
4. 位置：画面中下，头顶不顶边，上方留出标题空间
5. **脸不能被任何文字压住**（眼睛、鼻、嘴都不行）

---

## 三、设计层要求（这是「有设计感」的关键）

参考案例的封面不是「照片压字」，是**三层叠加**：

| 层 | 内容 | 说明 |
|---|---|---|
| 底层 | 暖光场景（室内暖灯 / 阳光街头 / 暖色书架） | 由 AI 生成，不用现成照片 |
| 中层 | 人物半身，正面 | 由 AI 图生图，保人脸 |
| 顶层 | 标题 + 色带 + 小标签 | **全部代码绘制**，不用模型画字 |

### 顶层元素清单

| 元素 | 样式 | 例子 |
|---|---|---|
| 主标题 | 白字 + 粗黑描边，1–2 行 | 「AI 接手决策」 |
| 关键词 | **暖黄/橙**，或手写体感 | 「决策」「效益」 |
| 色带条 | 黄底黑字，略倾斜，边缘毛糙 | 「效益差 5 倍」 |
| 小标签 | 圆角胶囊 + 图标 + 2–4 字 | 「拍板」「人效」「复利」 |
| 角标 | 右上/左上小方块 | 「下期」「必看」 |

### 图标怎么来

**不要用 emoji 直接贴**（跨平台字体会变）。用代码画简单几何图标（圆、方块、线条组合），或画在圆角底上。

## 四、尺寸

| 尺寸 | 用途 |
|---|---|
| 1080×1920 | 抖音 / 视频号首帧 |
| 1080×1440 | 小红书 / 抖音主页格子 |
| 1440×1080 | B站首页推荐 |
| 1920×1080 | B站个人空间 / 横版 |

**一套封面所有尺寸都要打开看**，尤其是 3:4 裁切后有没有切字、切头。

---

## 五、交付前自查

- [ ] 缩小到手机大小，第一眼是「明亮温暖」还是「暗冷」
- [ ] 有没有正脸，眼睛是否被遮
- [ ] 标题能不能一眼读完（3:4 建议 ≤2 行；9:16 可 3 行，但必须在中心裁切安全区内）
- [ ] 有没有至少 3 个设计元素（标题/色带/标签/角标）
- [ ] 3:4 裁切后文字是否完整
- [ ] 背景里有没有意外的文字或 logo（AI 生图常见）

## 七、即梦提示词标准（2026-11-02 采纳豆包建议后固化）

### 7.1 铁律：提示词只写绘图关键词

**绝不把笔记正文、分析、思考过程混进提示词。** 混进去画面必跑偏。

提示词只包含六段：主体 / 构图留白 / 光影色调 / 画风 / 画质 / 比例。

### 7.2 固定模板

```
【画面主体】一位三十岁中国男性企业家，正面半身，穿浅燕麦色纯色针织衫，
表情自信、直视镜头、微微带笑；
【构图留白】人物位于画面下半部、偏画面中间，头顶从画面高度四成处开始，
胸部以下被下边缘裁掉；画面上方三成保持干净的暖米色墙面留白，不放任何主体（这是底图版位要求，不代表标题可以贴顶；最终标题仍须位于中心裁切安全区）；
【光影色调】明亮温暖的暖色调，奶油米白、浅木色、暖黄灯光、柔和自然光侧入；
高调明亮，绝不阴暗；
【画风】商业海报质感，干净高级，生活感，ins 博主封面风格；
【画质】高清，细节丰富，浅景深；
【比例】3:4 竖版
```

### 7.3 反向提示词（必带）

```
文字，字母，数字，logo，水印，界面截图，招牌，字幕，
冷色调，蓝色，紫色，夜景，暗调，霓虹，
多余手指，畸形手，塑料皮肤，过度磨皮，美颜失真，拥挤，杂乱背景
```

### 7.4 图生图 > 纯文字

**有参考图就用图生图，参考强度 0.4–0.6。**

- 0.4–0.6：保留参考图风格，换成自己的主题
- 1.0：直接复刻参考图内容（错）

当前用 `image` 参数传人脸参考图，保证长相不变。

### 7.5 模型

- 首选 `doubao-seedream-5-0-pro-260628`（实测可用）
- `doubao-seedream-5-0-lite-260628` 在 ModelVerse 上返回 400，暂不可用

### 7.6 分工

| 谁做 | 做什么 |
|---|---|
| 即梦 | **只出底图**（人 + 背景 + 留白），绝不画字 |
| 代码 / 醒图 | 压标题、色带、标签、角标 |

AI 画中文必乱码。文字必须在后期加。

**正向提示词中不得出现「标题」「文字」等词**；需要留白时写「上方是干净空旷的天空/墙面，没有任何元素」。2026-11-02 曾因提示词写「用于后期加超大标题」，模型直接画出乱码英文。

## 八、一次失败的复盘（2026-11-02）

用户原话：**「你做的封面一直很差」**。

对照豆包的建议，我漏掉的是：

| 漏掉的 | 后果 |
|---|---|
| 没写反向提示词 | 画面里出现杂物、冷色、畸形手 |
| 提示词没分段结构 | 模型抓不住重点，出图「干净但没海报感」 |
| 没有「顶部预留 30% 空白」的硬指令 | AI 铺满画面，标题无处放 |
| 只用纯文字描述风格，没用朋友封面做图生图参考 | 复刻不出参考的配色和氛围 |

补上之后：底图从「寡淡的证件照」变成「暖光生活感海报」，标题也有了明确的落位。
